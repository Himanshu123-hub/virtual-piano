# 🎹 Virtual Piano – JavaScript DOM Project

## 📌 Project Overview

Virtual Piano is an interactive musical keyboard built using HTML, CSS, and JavaScript. This project allows users to play different musical notes by clicking on the piano keys or pressing the corresponding keys on their computer keyboard.

The main purpose of this project is to practice and understand JavaScript DOM manipulation, event listeners, keyboard events, audio handling, and interactive user interfaces.

## ✨ Features

- 🎹 Interactive Virtual Piano Keyboard.
- 🖱️ Play sounds by clicking on piano keys.
- ⌨️ Play sounds using computer keyboard keys (A–Z).
- 🔊 Different audio files assigned to different keys.
- 🎨 Visual key highlighting when a keyboard key is pressed.
- ⚡ Instant sound playback.
- 🔄 Reset audio playback position before playing again.
- 🎵 Multiple musical notes and sound effects.

## 🛠️ Technologies Used

- HTML5 – Structure of the piano keyboard.
- CSS3 – Styling and responsive layout.
- JavaScript – DOM manipulation and interactive functionality.
- JavaScript Audio API – Playing musical sounds.
- Event Listeners – Handling mouse clicks and keyboard events.

## 🎮 How to Use

1. Open the Virtual Piano in your browser.
2. Click on any piano key to play its sound.
3. Alternatively, press the corresponding key on your computer keyboard.
4. The pressed key will be visually highlighted.
5. Release the keyboard key to remove the highlighting.
6. Enjoy creating your own musical combinations!

## 🧠 JavaScript Concepts Learned

Through this project, I practiced and improved my understanding of:

- DOM Selection using `querySelectorAll()`.
- JavaScript Objects for storing audio file paths.
- `for...in` loop for iterating through object properties.
- Creating Audio objects using `new Audio()`.
- `forEach()` method for handling multiple elements.
- `addEventListener()` for click events.
- `keydown` event for detecting keyboard key presses.
- `keyup` event for detecting keyboard key releases.
- `toUpperCase()` for handling keyboard input.
- `find()` method for finding matching elements.
- `classList.add()` and `classList.remove()` for visual effects.
- `currentTime` and `play()` methods for audio playback.
